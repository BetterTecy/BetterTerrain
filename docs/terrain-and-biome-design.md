# 地形与生物群系设计概览

BetterTerrain 的主世界应呈现连贯的山脉、平原、河谷和海岸。玩家从山麓走向平原时，能看到地势逐渐开阔、河流向下游延伸，植被随海拔和水体条件变化。

## 世界生成的两个层次

1. **宏观骨架。** 先确定海陆轮廓、山脉走向、平原范围和主水系。山脉和平原能够跨越多个局部区域，主河道在流域内连通，并接到明确的下游或出水口。
2. **局部地形与群系。** 在骨架内设计山脊、丘陵、河谷和缓坡，再分布森林、草地、雪地等群系。局部地形的默认水平尺度约为 **64 × 64 区块**。相邻地貌自然衔接，河道跨区块延续。

## 可独立设计的内容

| 部分 | 设计目标 |
| --- | --- |
| 宏观地貌 | 决定世界整体的海陆比例、山脉走向和大片平原的位置。 |
| 水系 | 决定流域、河道、汇流点、出水口以及河谷和河岸的范围。 |
| 局部地形 | 决定区域内的高差、坡度、细节与相邻地形的过渡。 |
| 生物群系 | 决定什么环境下出现森林、草地或雪地，以及对应的地表材质和植被。 |

同一片森林可以覆盖平原和丘陵，同一座山可以有林地和雪地。调整山脊起伏时，整体山脉走向和主河道保持一致。调整森林分布时，基础地形和水系保持一致。

## 宏观地形目录

宏观地形决定跨多个局部区域的轮廓、高差和相邻地貌关系。下表列出供后续生成方案采用的地形及其典型形态。

| 类型 | 典型形态 |
| --- | --- |
| 山地与山脉 | 长条山脉、弧形山脉、并列山脉、分支山脉、块状山地 |
| 丘陵带 | 连绵丘陵、山前丘陵、低缓丘陵 |
| 高原 | 台地型高原、起伏高原、被深谷切割的高原 |
| 平原与低地 | 内陆平原、山前平原、沿海平原、冲积平原 |
| 盆地 | 山间盆地、内陆盆地。盆地可向外排水，也可形成封闭低地 |
| 谷地 | 沿山脉延伸的纵谷、横穿山脉的峡谷、向下游展宽的河谷 |
| 海岸与岛屿 | 缓坡海岸、陡崖海岸、半岛、近岸岛链 |
| 海洋地形 | 大陆架、大陆坡、深海平原、海沟、海底山脊 |

这些形态可以组合。并列山脉之间可以形成纵谷，山脉也可经山前丘陵过渡到沿海平原。山峰、鞍部、坡面和河岸由局部地形在宏观骨架上细化。

## 山地与山脉生成方案

以下为现有长条山脉之后的设计稿。长条山脉以连续主脊为骨架，脊线可近直、浅弯或呈缓 S 形。其余四种形态分别由明显转向的单条主脊、隔谷并行的两条主脊、可追踪的主支脊，以及多峰集中的紧凑山体形成。下列数值用于首轮固定陆地样例，水平距离以方块计，高程用世界 Y 坐标表示。沿用基底 Y=118、海平面 Y=63、云层 Y=384 和世界高度上界 Y=512。

| 形态 | 主脊或山体尺寸 | 全景识别特征 |
| --- | --- | --- |
| 弧形山脉 | 主脊弧长 5,120–6,144，累计转角 65°–110° | 一条持续转向的主脊，内侧低地有开口 |
| 并列山脉 | 两条主脊各长 4,608–5,632，重合段脊线横距 1,200–1,900 | 两条能分别追踪的脊线，中间有连续纵谷 |
| 分支山脉 | 主脊长 4,608–5,632，另有 1–2 条长 1,200–2,400 的支脊 | 主脊贯通，支脊从中段斜向伸出 |
| 块状山地 | 主轴 2,048–3,584，次轴 1,792–2,816，主次轴比不超过 1.6 | 轮廓紧凑，3–5 个主峰分布在多个方向 |

### 弧形山脉

1. 用种子确定弧线朝向、开口方向和转角，按弧长放置主脊控制点。在控制点之间施加小幅扰动，保持主脊从头到尾大体朝同一侧转向。
2. 沿局部法线生成内外侧坡面，内侧的山麓略窄，外侧向低地延展。两端逐步收窄并降低，将弧内低地通过至少一处宽 512 格的开口接到外围低地。
3. 沿弧线错开放置 2–3 座主峰。常规主峰为 Y=310–367，分到探云峰名额时可达 Y=392–408。用含开口的横剖面检查弧内低地和两端坡面。

### 并列山脉

1. 先生成纵谷轴线，再在两侧分别布置主脊。两条主脊共享大体走势，独立扰动曲率、宽度、长度和山峰位置。联合布置时按两条山脉计数。
2. 主脊有效重合长度至少 3,072 格。共同延伸的主要区段预留宽 320–640 格的谷底带，谷底比同一横断面上较低的主脊低至少 70 格。允许两侧山麓交叠，谷底高程上限由纵谷纵坡平滑控制。
3. 两条山脉采用不同的峰高和峰距。主峰沿纵向错开至少 512 格，较高一侧可分到探云峰名额。纵谷至少一端接到外围低地，并记录出口供水系生成使用。

### 分支山脉

1. 先生成一条连续主脊，在约 1/3 至 2/3 的位置选取分叉点。支脊以 30°–65° 的角度向外伸展；有两条时将接点错开至少 768 格。
2. 在接点共享主脊高程，沿支脊前 384–768 格平滑过渡到自身脊线高程和宽度。离开汇接段后，支脊主峰比主山脉最高峰低至少 24 格，末端逐步退入山麓。
3. 在主脊与支脊之间留出向外张开的谷地。支脊随所属主脊计为一条山脉，全景可显示分叉，山段视图能分别追踪各支脊。

### 块状山地

1. 用种子确定不规则近椭圆形范围，在内部布置 3–5 个间距至少 512 格的主峰。主峰应分布在至少三个方向，高程为 Y=260–345。
2. 用 2–4 条短脊和鞍部连接各主峰，鞍部比其连接的较低一峰低 35–80 格。以共同山麓衔接外缘，坡面随距山体中心和短脊的距离平滑退到基底。
3. 从外缘保留至少两个朝向不同、各宽至少 256 格的谷口，谷坡向外降低。块状山地以整片山体独立标记，首轮样例的 16,384 格窗口内布置 0–1 片。

### 布点、衔接与预览验收

- 继续用每轴 8,192 格的区划布点。首轮对齐的 2 × 2 区划组合使用四条长条山脉、一条弧形山脉、一组含两条主脊的并列山脉和一条分支山脉，共八条可追踪主脊。用区域种子打散各类型的位置和走向。任意平移的 16,384 × 16,384 格窗口按主脊锚点统计，跨多个窗口的平均目标为 7–9 条。全景单独显示块状山地。
- 每个对齐组合分配两座探云峰，总量由共享名额控制。峰和支脊各有独立的种子盐。固定旧版长条山脉的生成配置，通过新版本配置试验混合布局。地图远处按相同规则延续。
- 每种山体生成后记录主脊线、影响范围、峰和谷口。区块采样时只查询范围相交的候选，候选索引覆盖越过区划边界的山体。相邻山麓按较高地面合成并平滑过渡。内弧开口、纵谷和分叉谷用连续高程约束保持畅通。谷口坐标和坡向供水系后续接入。
- 缓存区划内的脊线分段和各段影响范围，继续按水平列计算高程。性能以版本 4 为基线，在同一种子、区块范围和 JVM 配置下分别预热后测三次，首轮目标为生成耗时中位数增幅不超过 25%。
- 用种子 `42` 和 `12345` 在原点及远处正负坐标复采。先用 16,384 格全景核对主脊数量与形态，再用 4,096 格窗口检查弧内开口、纵谷、分叉与谷口，用近景剖面测距离和高差。每个种子至少选一片块状山地检查峰与鞍部。最后在 Minecraft 的真实区块核对山脊高度、跨区连接与云层位置。

## 首期预期效果

在可选的 BetterTerrain 主世界预设中，用固定种子展示连续山脉、平原带和一条跨越多种局部地形的主河道。能够观察到平原、丘陵和山地之间的过渡，并独立调整至少两种群系的分布。
