# 地形与生物群系设计概览

BetterTerrain 的主世界应呈现连贯的山脉、平原、河谷和海岸。玩家从山麓走向平原时，能看到地势逐渐开阔、河流向下游延伸，植被随海拔和水体条件变化。

## 世界生成的两个层次

1. **宏观骨架。** 先确定海陆轮廓、山脉走向、平原范围和主水系。山脉和平原能够跨越多个局部区域，主河道在流域内连通，并接到明确的下游或出水口。
2. **局部地形与群系。** 在骨架内设计山脊、丘陵、河谷和缓坡，再分布森林、草地、雪地等群系。局部地形的默认水平尺度约为 **64 × 64 区块**。相邻地貌自然衔接，河道跨区块延续。

## 可独立设计的内容

| 部分 | 设计目标 |
| --- | --- |
| 宏观地貌 | 决定世界整体的海陆比例、山脉走向和大片平原的位置。 |
| 水系 | 决定流域、河道、汇流点、出水口以及河谷和河岸的范围。 |
| 局部地形 | 决定区域内的高差、坡度、细节与相邻地形的过渡。 |
| 生物群系 | 决定什么环境下出现森林、草地或雪地，以及对应的地表材质和植被。 |

同一片森林可以覆盖平原和丘陵，同一座山可以有林地和雪地。调整山脊起伏时，整体山脉走向和主河道保持一致。调整森林分布时，基础地形和水系保持一致。

## 首期预期效果

在可选的 BetterTerrain 主世界预设中，用固定种子展示连续山脉、平原带和一条跨越多种局部地形的主河道。能够观察到平原、丘陵和山地之间的过渡，并独立调整至少两种群系的分布。
