# 局部地形模块规范

在宏观地貌和水系范围内细化平原、丘陵、山地与河谷。局部地形可独立配置，默认水平设计尺度约为 **64 × 64 区块**。

- 输入为宏观地貌、水系和局部地形配置。
- 输出为更细的地形轮廓、高程和坡度，供群系与区块生成使用。
- 不同地形应自然过渡。局部调参应产生目标范围内的变化，并保留宏观山脉、河道、河床和水位。
