# 宏观地貌模块规范

建立能跨越多个局部区域的海陆轮廓、山脉和平原带，形成主世界的整体地势。

- 输入为世界种子、预设和宏观地貌配置。
- 输出为海陆范围、山脉走向与范围、平原范围和粗高程，供水系及局部地形使用。
- 相邻区域的地貌应连续。局部地形的默认尺度约束用于下游细节，山脉和平原带可以跨越多个局部区域。

适用于本目录和对应的生成资源。

## 长条山脉预览

样例 ID 为 `betterterrain:long_mountain_preview`，配置版本为 4。世界以 8,192 × 8,192 格区划布点，每个区划有两条山脉，从种子、区划坐标和区内序号获得稳定标识。每格高程同时采样本区及轮廓可达的邻区。任意平移的 16,384 × 16,384 格窗口按山脉中心统计，目标平均约八条。

| 输入或尺度 | 单位、默认值与范围 |
| --- | --- |
| 大陆度 | 无量纲，输入范围 `[-1, 1]`。0 以下取基底，0 至 0.3 逐步抬升。样例输入为 0.72。 |
| 基底高程 | 世界坐标 Y，单位为方块。样例固定为 Y=118。 |
| 山脉 | 单条山脉沿主方向长 5,120 至 5,632 格。两侧含山麓宽约 1,110 至 1,470 格。主脊包含近直、单弧、缓 S 形，布点区的四种主方向带有种子扰动。 |
| 脊线高程 | 每条山脉有两座主峰。普通主峰为 Y=310–367，对齐的 2 × 2 个布点区内有两座 Y=392–408 的探云峰，非主峰控制点相对基底抬升 100 至 134 格。 |
| 侵蚀与山地权重 | 无量纲。侵蚀由基底的 0.86 连续下降到主脊的 0.16，山地权重由 0 增至 1。 |

布点关系包括谷地分隔、外坡交叠和端部主脊汇接。对齐的 2 × 2 个布点区有一对谷地、两对山麓交叠、一对主脊汇接。范围相交时按较高的地势合成，两侧高程接近的地方做有界平滑。单条山脉的侵蚀和山地权重可独立采样，复采相同世界坐标的结果与缓存和查询顺序无关。样例的主峰与相邻显著鞍部至少相差 40 格，沿脊间距至少为 768 格。

预览的全景、山段、近景和单方块窗口分别覆盖每轴 16,384、4,096、1,024 和 256 格，采样间距分别为 64、16、4 和 1 格。每档按列中心取样并向下取整，每个窗口为 256 × 256 列。全景为中心落入窗口的山脉提供定位点，优先选窗口内的最高峰，靠近地标时按距离加载嵌套的精细窗口。细层接缝用两侧高程差补齐垂直面。峰顶标注使用主脊位置的原始采样值。海平面 Y=63、云层 Y=384、上界 Y=512 为网页中的世界坐标参照。

同一张地图支持透视环绕与第一人称自由飞行。预览用海拔和坡度为地表选择草地、岩石或积雪，露出的方块侧面使用对应的草地、泥土、岩石或雪线像素材质。这些规则属于网页展示。切换观察视角和材质时，高程数据和地貌验收一致。

游戏预设 `betterterrain:terrain_preview` 按同一组大陆度与基底高程采样。密度编译时通过 Mixin 将真实世界种子传给 `betterterrain:mountain_height`，原版噪声仍委托给原编译上下文。每 4 格水平插值，垂直方向复用列高，密度以高程与方块 Y 的差计算。原版温湿噪声和群系参数参与群系匹配，原版材质规则、区块特征、含水层、面条洞穴与结构地形适配继续参与生成。本期固定大陆度和基底，覆盖海陆过渡的地形算法在后续阶段接入。

## 混合山地网页预览

网页样例 ID 为 `betterterrain:mixed_mountain_preview`，配置版本为 5。每个对齐的 16,384 格区域将四种布点组合随机分配给四个 8,192 格区域，最终输出四条长条、一条弧形、两条并列和一条分支主脊。分支附在主脊图上，块状山地作为单独标记。每个对齐区域有两座 Y=392–408 的探云峰。布局以世界种子和区域坐标为输入，固定陆地基底为 Y=118。

主脊以弧长参数取样，高程沿脊线和向两侧坡脚连续插值。并列山脉共享方向、保持脊距并错开峰位，支脊使用主脊高程作为接点起始值。块状山地由紧凑范围内的多峰、鞍部与短脊组成，山麓向外缘连续消退。以 1,024 格子区缓存相交山体的候选范围。网页使用同一采样器导出四级网格，独立在地图上标注主脊类型、支脊和块状山地。
