# 宏观地貌模块验收

用同一种子和预设检查覆盖多个局部区域的宏观样例。保存粗高程图，标出海陆边界、山脉沿线及平原范围。

- 样例中的山脉沿指定方向连续延伸，平原形成连片低地。
- 在区域边界两侧复查坐标与地势，确认山脉和海陆边界按样例衔接。
- 调整一个宏观地貌参数时，用相同样例检查目标变化，并复验受影响的水系与局部地形。

## 长条山脉预览

在仓库根目录用 JDK 25 执行 `.\gradlew.bat checkTerrainPreview terrainPreview`。自动检查也随 `build` 运行。样例为 `betterterrain:long_mountain_preview`（版本 4），种子为 `42` 和 `12345`，观察窗口中心为 `(0, 0)`、`(98304, -65536)`、`(-131072, 81920)`。

- 每个对齐窗口按中心统计八条山脉，核对四组走向、三种弯曲、主脊连续性和两座探云峰。按 X、Z 各自偏移 −3,000、0、3,000 格复采，每种子共 27 个统计窗口，平均值应在七至九条。沿谷地、交叠坡面和主脊汇接方向取样，并按多条布点区 X/Z 边界复查相邻高程。两个方向均须观察到跨区延伸的山地。
- 单条旧样例沿用 `(-512, -512)`、`(512, -512)`、`(-512, 512)` 三个 1,024 格窗口起点，逐点比较公用边界和反向并行采样。全域采样器在原点和远处的四档高程须通过反向并行复采。导出时验证所有精细窗口位于父窗口内部并与外层网格对齐。
- 运行 `.\gradlew.bat serveTerrainPreview`，打开 <http://127.0.0.1:8765/>。切换原点和远处观察窗口，检查全景中的主脊和定位点。点选山脉后用滚轮靠近与拉远，核对山段、近景和单方块切换。检查方块顶面、两侧拼接、云层参考面和所选山脉的两条剖面。点击「自由飞行」，检查 `WASD` 移动、空格和 `Shift` 升降、鼠标环顾与返回透视。
- 数据和网页位于 `build/terrain-preview/`。每个网格为 256 × 256 列，原始 `.i16` 高程文件为 131,072 字节，按行优先、小端有符号整数编码。网络面板中初次进入只请求当前种子的全景网格。

记录首帧与切换结果、导出耗时、剖面与截图路径。游戏预设通过根验收的 PCL 实例一键启动检查，比较真实区块山脊坐标、高度图和相同种子的宏观高程。

## 混合山地网页预览

使用相同的构建命令、种子和观察窗口。构建同时保留版本 4 的回归检查，网页导出版本 5 的数据。

- 六个默认窗口均须有八条主脊与一片块状山地，主脊组成须为四条长条、一条弧形、两条并列和一条分支。复测每种子 27 个平移窗口，主脊平均数在七至九条。对齐窗口内的两座探云峰在 Y=392–408。
- 自动核对弧形转角与开口、并列谷底落差、分支连接和衰减、块状山地峰距及短脊数量。复查两轴区划边界和反向并行采样。
- 打开网页，核对右侧地标类型、编号 1–8 和块状山地 M。选中并列山脉查看横穿山峰的剖面，选中分支山脉检查支脊，选中块状山地检查相邻峰和鞍部。切换窗口、精度和自由飞行。确认首次只载入一个全景高程网格。
